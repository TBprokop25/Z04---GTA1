# Chaos City (Z04)

Top-down 2D hra inspirovana GTA 1. Kradni auta, znic mesto, vydelavej na chaosu a utikej pred policii a armadou.

## Ovladani
| Klavesa | Akce |
|---|---|
| WASD / sipky | chuze, jizda |
| Shift | beh (pesky) / nitro boost (v aute) |
| Mys (LMB) | strelba / kanon tanku |
| E | nastup / vystup z auta, pouziti budovy |
| Space | rucni brzda (smyk zanechava stopy) |
| Q | dalsi zbran |
| F | schovat / vytahnout zbran |
| B | obchod (zbrane 1-6, brneni 7) |
| N | novy sidequest |
| M | velka mapa |
| E u dveri | vstoupit do budovy |
| E uvnitr | pouzit stanici / odejit (dvere dole) |
| P / ESC | pauza (venku) / odejit z budovy |

## Co je noveho
- **Vstup do budov** klavesou **E**: banka (sejf + ucet), nemocnice (luzko, darovani krve), ukryt (ulozeni, trezor, prevleknuti), zbrojnice (obchod), vecerka (zdravi/brneni). Uvnitr chodis a pouzivas stanice klavesou E.
- **Bankovni ucet**: ulozene penize jsou v bezpeci i po smrti (v nemocnici ztratis 20 % jen z hotovosti).
- **Vetsi mesto** (12x12 bloku) a sest budov se sluzbami: lakovna, banka, nemocnice, ukryt, zbrojnice, vecerka.
- **Cyklus den/noc** - v noci sviti pouliclni lampy, okna budov a reflektory aut.
- **Vice vozidel**: sedan, dodavka, autobus, motorka, sanitka (ruzna velikost i rychlost).
- **Zbrane + brneni**: granat, brneni (pohlcuje poskozeni, kupuje se v obchodu nebo padi z policie).
- **Nitro** v aute (Shift) s plameny z vyfuku a stopami pneumatik ve smyku.
- **Hledanost**: na 3+ hvezdach policejni zatarasy, na 5 hvezdach bojovy vrtulnik.
- **Zvuk**: procedurálne generovane vystrely, vybuchy, siréna, motor, nitro.
- **Ukladani**: rekord a penize se ukladaji (quest / banka / ukryt / smrt). Rekord je v menu.
- **Animace**: chodci i hrac maji kracejici nohy a ruce, muzzle flash, lezici tela.

## Tipy
- Chaos combo nasobi odmeny az x5, kdyz nicis rychle za sebou.
- Ze znicenych aut a policistu padaji lekarnicky (bily kriz), penize ($) a brneni (modry stit).
- Lakovna (ruzova budova): zajed autem k vratum, auto se opravi a hvezdicky zmizi ($300).
- Banka (zlata budova): jdi k dverim pesky, stiskni E a 12 s vydrz - odmena $4000+, ale hledaji te 3 hvezdy.
- Ukryt (zeleny): smaze hvezdy a ulozi hru. Nemocnice (cervena): plne vyleceni.
- Vrtulnik lze sestrelit - pada z nej hodne penez a brneni.
- Pokud policii ujedes dostatecne daleko, hledanost rychle klesa.
